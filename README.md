# BODY FORM STUDIO

Інклюзивна віртуальна 3D-примірочна для підбору одягу та білизни на моделях із різними пропорціями тіла.

**Статус:** MVP 0.1 — інтерактивний прототип із процедурним 3D-манекеном, не симулятор реальної посадки.

## Що вже працює

- Справжня WebGL/Three.js-сцена з обертанням, масштабуванням і ракурсами.
- Чотири базові фігури: збалансована, пишна, худорлява, мускулиста.
- Регулятори зросту, грудей, талії, стегон, плечей, мускулатури й живота.
- Незалежне налаштування грудної зони й нейтральної передньої посадки виробу.
- Демонстраційні види одягу: боді, бюстгальтер, білизна, сукня.
- Кольори тканини: burgundy, charcoal, champagne, ivory.
- Локальне збереження профілю у браузері (без серверної передачі).
- Адаптивний інтерфейс для комп'ютера й телефона.

## Технології

- HTML + CSS + JavaScript (ES modules)
- Three.js та OrbitControls через jsDelivr; без збірки та npm
- GitHub Pages для хостингу статичного сайту

## Як запускати

Відкрий опублікований сайт через GitHub Pages. Для локального запуску використовуй простий HTTP-сервер (ES-модулі можуть не працювати з file://). На комп'ютері нічого встановлювати для перегляду сайту не потрібно.

## Структура

- \`index.html\` — структура інтерфейсу
- \`assets/css/styles.css\` — dark premium UI
- \`assets/js/app.js\` — Three.js сцена, геометрія манекена та інтерактивність

## Принципи інклюзивності

Зовнішність, тип статури й анатомічні параметри — різні незалежні налаштування. Жодна трансгендерна жінка не зобов'язана відповідати певному профілю тіла. Усі анатомічні налаштування необов'язкові.

## Обмеження MVP

- Процедурна геометрія стилізована, вона не є фотореалістичною 3D-моделлю та ще не відповідає якості референсів.
- Одяг — демонстраційна геометрія, а не фізична симуляція тканини.
- Параметри не підтверджують фактичний розмір і не є медичним або компресійним рекомендаційним інструментом.
- Для наступної версії потрібні деталізована GLB-модель, морф-таргети, викрійки виробів, фізика посадки та каталог.

## Наступні ітерації

1. Деталізований mesh манекена з морфінгом і плавними переходами.
2. Нормалізована система анатомічних параметрів і вимірювань.
3. 3D-моделі товарів, примірка з реальними лекалами.
4. Збереження образів, профілі користувачок за добровільною згодою.
