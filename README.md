# BODY FORM STUDIO

Інклюзивна 3D-примірочна для підбору одягу та білизни з урахуванням різних пропорцій тіла. Це дослідний прототип, а не медичний сервіс і не точний симулятор посадки одягу.

**Версія:** MVP 0.6 — справжня параметрична GLB-модель, додатково процедурний резерв.

**Сайт:** https://mrschljakhta-max.github.io/body-form-studio/

## Реалізовано

- Інтерактивна WebGL-сцена Three.js, 360°, вигляд спереду/збоку/ззаду, zoom і premium-подіум.
- Основний реалістичний CC0 манекен з MakeHuman на основі GLB (~4.14 MB), морф-таргети для пропорцій тіла, риг (Mixamo skeleton).
- 4 пресети: збалансована, пишна, худорлява, мускулиста.
- Зміна зросту, грудей, талії, стегон, плечей, мускулатури, живота; окремий блок анатомії/посадки.
- Нейтральний матеріал «слонова кістка» та безлика порцелянова маска голови (поверх 3D-сітки).
- Демонстраційні типи одягу (боді, бюстгальтер, білизна, сукня) в режимі процедурного fallback.
- Локальне збереження профілю браузером. Немає передачі особистих вимірів на сервер.
- Адаптивний інтерфейс для мобільних екранів.

CC0-вихідні дані MakeHuman / MPFB2 включені до репозиторію творців моделі:
https://github.com/nirholas/three.ws/tree/main/avatar-sources/anny

Опис походження, авторства та CC0:
https://github.com/nirholas/three.ws/blob/main/avatar-sources/anny/README.md

Файл завантажується напряму з GitHub Raw; він не зберігається в цьому репозиторії. При збої мережі або помилці CORS активується локальна процедурна модель. Залежність від зовнішнього джерела слід прибрати перед комерційним запуском.

## Технології

- GitHub Pages, без npm/build

## Архітектура

- `index.html`: інтерфейс і панелі керування
- `assets/css/styles.css`: адаптивні стилі
- `assets/js/app.js`: події, UI, 3D-сцена, перемикання моделей
- `assets/js/premium-model.js`: завантаження GLB, зміна морфів, порцелянова маска
- `assets/js/mannequin.js`: процедурна резервна модель

## Поточні обмеження

- Параметри слайдерів керують візуальними морфами та **не означають точно виміряні сантиметри моделі**.
- Морфи можуть не відповідати всім індивідуальним особливостям тіла.
- Демонстраційний одяг із резервної моделі не є викрійками. Для преміального GLB повноцінну систему одягу ще треба адаптувати до його сітки та скелета.
- Немає фізики тканин, оцінки компресії, гарантій реального розміру чи комфорту.
- Потребує тестування на різних браузерах та мобільних GPU.
